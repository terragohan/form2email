For coding tools

Set up a form without touching this website — paste one prompt into your coding tool and let it do the wiring.

The prompt

Paste this into your agent (Claude Code, Kimi Code, Cursor, …):

Set up a Form2Email endpoint for this project.

1. Ask me for the destination email address and the domain my form will
   live on (origin).
2. Create the endpoint:
   curl -s -X POST {{ settings.base_url }}/api/endpoints \
     -H 'content-type: application/json' \
     -d '{"destination_email": "<destination>", "origin": "<origin>"}'
3. The response has public_url (form target), manage_url (API), and
   manage_page_url (human page). All three are secret — store them in my
   project's config, never in public code.
4. Tell me to click the verification link in the destination inbox — a
   human must do this; nothing works until it happens. Also tell me to
   add {{ settings.mail_from }} as a trusted sender.
5. Once I confirm verification, wire my form to POST public_url.
   Submissions are only accepted from the registered origin (exact
   hostname match; register a subdomain separately if the form lives on
   one).
6. Remind me: the endpoint expires {{ settings.default_ttl_days }} days after
   verification. Extending is free (+{{ settings.default_ttl_days }} days per call) via
   POST <manage_url>/extend — the manage page has a button.

One thing no tool can do for you: clicking the verification link. The endpoint stays inert until a human does.

What the tool will do

  1. Create

    POST /api/endpoints with your destination address and form domain. Rate-limited to {{ settings.rate_limit_create_per_hour }}/hour per IP.

  2. You verify

    A verification link lands in the destination inbox — single-use, 24 hours. Add {{ settings.mail_from }} to your trusted senders so it doesn't get filtered.

  3. Wire the form

    The tool points your form at public_url — form-encoded or JSON, up to {{ settings.max_submission_body_bytes // 1024 }} KB. Browser posts must come from the registered origin exactly.

  4. Stay active

    {{ settings.default_ttl_days }} days per window, free extensions from the manage page. The tool can also call POST <manage_url>/extend directly.

Machine-readable

Coding tools can discover the API themselves:

  • {{ settings.base_url }}/api/info — the whole API as JSON: operations, fields, errors, limits
  • {{ settings.base_url }}/llms.txt — this guide as plain text, in the llms.txt convention
  • {{ settings.base_url }}/openapi.json — the OpenAPI schema
