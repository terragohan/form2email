{% extends "guide-base.html" %} {% block heading %}A quote request form that emails you{% endblock %} {% block standfirst %}Let clients describe the job, the budget, and the timeline up front — every request lands in your inbox, ready to reply to.{% endblock %} {% block about %}

If you sell services — contracting, consulting, freelance work, an agency — the first exchange with a new client is always the same questions: what do you need, what can you spend, and when. A quote request form asks those questions once, so you can size up the lead before you spend time pricing the work.

A plain HTML form on your existing site is enough. Form2Email receives the submission and emails it to you with the requester's address as reply-to — no backend, no account, no CRM to wire up.

Swap the service and budget options for your own — the markup is plain HTML and styling is up to you. Only the action, method="post", and the name attributes matter to Form2Email; selects and radio groups are submitted as ordinary fields like any text input.

{% endblock %} {% block mapping %}

Each quote request becomes one email to your destination address:

  • Reply-To is the requester's email, so hitting reply answers them directly with your quote.
  • name and message appear in the body.
  • phone, service, budget, and timeline are listed as additional fields — a select or radio choice arrives as its plain text value.

With _redirect set, the requester's browser is sent to your thank-you page after a successful submit. Without it they get a small JSON response — fine for JavaScript-driven forms, less friendly for plain HTML.

{% endblock %} {% block tips %}
  • Ask about budget and timeline in the form itself — that's what qualifies the lead before you spend an hour on a call or a quote.
  • Keep required fields minimal. Name, email, and the project description are enough; leave phone and timeline optional so people don't bounce.
  • Offer a "not sure yet" option on budget — people who skip the question still send the form.
  • Say on your thank-you page when you respond (e.g. "within one business day") — the requester gets no automatic confirmation email.
  • Add {{ settings.mail_from }} to your contacts so the verification and submission emails don't land in spam.
{% endblock %} {% block limitations %}
  • Selects and radio groups aren't special to Form2Email — they arrive as additional fields with the chosen value as plain text. There is no formatted quote document, just one email per request.
  • Longer forms are fine within the caps: the message field accepts up to 20,000 characters, and you can have up to 20 additional fields of 1,000 characters each.
  • Quote forms tend to run for months, so remember the endpoint expires {{ settings.default_ttl_days }} days after verification — extend it for free from your manage page (extending also revives an expired endpoint), or ask the operator for a permanent endpoint.
  • Submissions are accepted only from the exact domain you registered. If your site answers on both yoursite.com and www.yoursite.com, register the one your form is served from (or create one endpoint per hostname).
  • No file attachments — if you want reference photos or briefs, ask for a link instead.
